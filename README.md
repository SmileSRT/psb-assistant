# ПСБ-Ассистент

## Требования
Для запуска проекта необходимы предустановленные пакеты 
- docker
- docker-compose


### docker & docker-compose
В зависимости от используемой ОС установка docker и docker-compose проходит по разному.
Изучите официальную документацию для своей ОС: https://docs.docker.com/


## Запуск
Введите в терминал команду:
```
$ docker-compose up --build
```
Дождитесь, пока поднимутся все контейнеры и API сможет принимать запросы

## Остановка работы
Необходимо прервать работу контейнера и опустить сетевые интерфейсы:
```
Ctrl + C
$ docker-compose down
```

## Документация к API
Так как в docker-compose.yml файле описана конфигурация для двух сервисов (оба работают на fastapi-python), вы можете проверить документацию через Swagger по ссылкам:
- `http://localhost:8080/docs` --- inference-service
- `http://localhost:8000/docs` --- ml-service

## Краткое описание решения
Запускается два контейнера: 
- ml-service
- inference-service

### ml-service 
Выполняет дамп данных в хранилище фичей `Feast`, в качестве онлайн-хранилища используется `sqlite`
После успешной загрузки фичей предоставляет интерфейс для получения типов параметров, их значений, количества и др.

### inference-service
Загружает из файла с весами модель, обученную на датасете, формата хранящегося в `Feast`

При запросе `POST http://localhost:8080/predict` с указанием ИНН выполняется запрос к ml-service на получение кортежа актуальных фичей из хранилища. Далее происходит инференс.

Ответ включает состояние признаков по квази-дефолтности и некоторые признаки по кодам финансовой отчетности. По этим данным строятся основные характеристики.
